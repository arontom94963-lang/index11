What runs behind the prediction?

1. Weighted score:

z = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ

2. Sigmoid conversion: the score is converted into a probability.

P(Converted = 1) = 1 / (1 + e-z)

3. Classification: the probability is later compared with the chosen threshold (0.50 by default).

prediction = 1 if probability ≥ 0.50 prediction = 0 if probability < 0.50

In Python, the learned values can be inspected with:

model.coef_ # learned coefficients model.intercept_ # intercept model.predict_proba(X_test)[:, 1] # probability of class 1
Behind the scenes: model.fit(X_train, y_train) learns the coefficients (β values) and intercept from the training data by optimizing the logistic-loss objective. The learned coefficients determine how each input contributes to the model score. The sigmoid function then turns that score into a probability between 0 and 1.
Explanation: This step now shows the internal flow of Logistic Regression: input features → weighted score → sigmoid probability → threshold → final class. The actual coefficient values depend on the trained dataset and are not hard-coded here.
